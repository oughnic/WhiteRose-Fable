# Integration and branding contract

This repository is one of two public faces of the same model, and one of three repositories
that make the offering:

| Repository | Role |
|---|---|
| `oughnic/mauro-edit` (private) | The model source and every generator (DITA, SVG, RDF; the concepts manifest) |
| `oughnic/contsys.org` | The reference publication (DITA → OxygenXML WebHelp) — "look it up" |
| `oughnic/WhiteRose-Fable` (this repo) | The hospital — "walk it through" |

The pair are one product with two front doors: **read the reference, or walk the hospital**.

## Identity

- **Master brand:** ContSys. The property names are subordinate and disposable; *ContSys*,
  *continuity of care*, and *continuity across care* are not.
- **This property:** **White Rose General Hospital** — a fictional 1960s NHS district general
  in the Aire valley. (Fictional: never use the name or identity of the real Airedale General
  Hospital or any other actual NHS body.)
- **Logo:** the Yorkshire rose (`public/rose.svg`) — [`Yorkshire rose.svg`](https://commons.wikimedia.org/wiki/File:Yorkshire_rose.svg)
  by Booyabazooka (English Wikipedia), via Wikimedia Commons, **CC BY-SA 3.0**. Attribution
  travels in the README and inside the SVG; derivatives of the rose remain BY-SA.
- **Period NHS styling** (NHS blue signage, 1960s fabric) is a deliberate owner decision and
  stays. Interface text is Arial/system today; if typography is revisited, Lato is the bridge
  face shared with the reference, and the reference's maroon `#530008` is the shared accent.

## Language

- Master strapline: **"A working model of health and social care — one you can walk around."**
  Support line: *"Every concept has an address: look it up, or walk to it."*
- Property lines: reference — **"Look it up."** · hospital — **"Walk it through."**
- Audience line: *"for everyone who plans, provides, or builds care"* (the shared-language
  value is stated by naming audiences, never as "IT and non-IT").
- **Term rule:** "continuity of care" is the standard's term (3.1.6) and must be exact wherever
  the concept is meant. "Continuity across care" is permitted only as marketing amplification
  in straplines and free prose.

## URL contract

- Canonical concept URL: **`https://contsys.org/concept/{slug}`** — the *persistent*
  identifier. **Slugs use underscores**, matching the URLs already live at contsys.org:
  lowercase the standard's term and replace spaces with `_`, keeping any real hyphens in the
  term (`care plan` → `care_plan`; `subject of care` → `subject_of_care`; `self-care` →
  `self-care`). Hyphenated forms (`care-plan`) are accepted as aliases that redirect to the
  underscore form. The reference's internal DITA file names are hyphenated
  (`care-plan.html`) — that mapping (`_` ↔ `-`) is the serving layer's job, never a reason
  to change a public URL.
- The hospital is served at **`https://contsys.org/hospital/`** (GitHub Pages remains as a
  staging deployment).
- Mauro UUIDs are a per-export working key only — **they are not guaranteed stable between
  exports**. Nothing in this repo may treat a UUID as persistent; link and join by slug.
- Renames are governed by an alias registry in the concepts manifest: an old slug 301s to the
  new one. Deep links must therefore tolerate redirects.

## The concepts manifest (the join)

Generated by mauro-edit alongside each export; consumed by `tools/build-world.mjs`:

```json
{ "slug": "care_plan", "label": "care plan", "uuid": "3a36d00e-…",
  "aliases": ["care-plan"], "docsPath": "/concept/care_plan",
  "hospital": "/hospital/?concept=care_plan" }
```

Rules: slug is canonical; `uuid` binds only this export; label change ⇒ new slug + old slug
appended to `aliases`; uuid change under a stable label ⇒ rebind silently; both changed ⇒ the
build must fail and ask a human.

## Integration points (work items)

1. ✅ **Deep links in:** `?concept=` accepts the underscore slug, the hyphen alias, or the
   spaced label (`src/contsys.ts` `conceptKey`).
2. ◐ **Deep links out:** each concept's reader (R) links "Full definition —
   contsys.org/concept/{slug}". *Open:* the same link from porter results; lobby posters are
   canvas textures and stay unlinked.
3. **Cross-property switcher:** a persistent menu item each way — hospital: "Read the
   reference"; reference: "Walk the hospital".
4. **Postgraduate Medical Centre as the knowledge resource:** library/reading room ← the
   reference's introduction themes; lecture theatre ← use cases and the two coupled cycles;
   seminar room ← the master diagrams; foyer noticeboard ← what's new, model version,
   licensing. Annexes already hang off the PGMC — follow that pattern.
5. ✅ **Presenter mode:** `?present=1` starts with the interface hidden (equivalent to H);
   L dims the house lights.
6. **Named viewpoints:** `?view=lectern|wide|audience` (lectern exists as `?start=theatre`).
7. **Screen control:** `?deck={url}&slide={n}` — and same-origin access to the reference's
   figures (`/images/figure-*.svg`) once both properties share contsys.org.
8. **Capture quality:** a toggle for capture-grade rendering (pixel-ratio, shadows) distinct
   from browsing quality.
9. **Starter deck:** commit a `public/slides/manifest.json` so the theatre does not open on
   the built-in instructional deck.
